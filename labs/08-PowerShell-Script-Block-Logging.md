# Lab 08 - PowerShell Script Block Logging

## Objective

Configure PowerShell Script Block Logging through Group Policy and verify that PowerShell activity is recorded in the Windows PowerShell Operational log.

## Environment

- Domain: `corp.northstar.local`
- Domain Controller: `WIN-SRV-DC01`
- Operating System: Windows Server 2022
- GPO: `NorthStar - PowerShell Logging`
- Target OU: `Domain Controllers`

## Configuration

Created the `NorthStar - PowerShell Logging` GPO and enabled:

**Computer Configuration > Policies > Administrative Templates > Windows Components > Windows PowerShell > Turn on PowerShell Script Block Logging**

The GPO was linked to the **Domain Controllers** OU.

## Security Baseline Review

Downloaded and reviewed the Microsoft Windows Server 2022 Security Baseline package. Looked through the included documentation and Group Policy reports to understand the security settings recommended for Windows Server 2022.

The full baseline was not imported or applied to the domain controller. Instead, PowerShell Script Block Logging was configured separately using the `NorthStar - PowerShell Logging` GPO.

## Verification

Ran:

```powershell
gpupdate /force
```

The Group Policy update completed successfully.

Then ran:

```powershell
gpresult /r /scope computer
```

`NorthStar - PowerShell Logging` appeared in the list of applied computer policies, confirming that the GPO was being applied to `WIN-SRV-DC01`.

## Event Log Verification

Opened:

**Event Viewer > Applications and Services Logs > Microsoft > Windows > PowerShell > Operational**

The log contained **Event ID 4104** events for PowerShell Script Block Logging.

To verify that the newly configured policy was recording PowerShell activity, ran:

```powershell
Write-Output "Lab 08 Script Block Logging test"
```

A new Event ID 4104 appeared with a timestamp matching the test. The event contained the test text, confirming that the script block was logged.

## Result

PowerShell Script Block Logging was successfully configured and verified on `WIN-SRV-DC01`.

The lab covered:

- Creating and configuring a Group Policy Object
- Linking the GPO to the Domain Controllers OU
- Verifying applied Group Policy settings
- Reviewing PowerShell Operational events
- Identifying Event ID 4104
- Performing a controlled test to confirm script block logging

## Notes

Several existing Event ID 4104 events were present in the log before the controlled test. Those events were not used to determine whether the activity was malicious or whether it was generated by the new GPO. The controlled test was used to verify the current logging configuration.
