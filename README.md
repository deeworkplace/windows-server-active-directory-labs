# Windows Server and Active Directory Labs

Hands-on home lab documenting Windows Server administration, Active Directory, DNS, DHCP, Group Policy, security auditing, Windows client administration, and Microsoft Entra hybrid identity.

## Active Directory Home Lab Curriculum

This repository documents practical exercises performed in a virtualized Windows environment. The labs cover foundational domain services, user and group administration, security configurations, troubleshooting, and hybrid identity.

The curriculum is organized into five phases, progressing from Windows Server fundamentals to Active Directory administration and Microsoft cloud integration.

## Lab Environment

| Component | Configuration |
